# AI Agent 基础概念

## 什么是 AI Agent

AI Agent（智能体）是一种能够自主感知环境、做出决策并执行行动的 AI 系统。与传统的聊天机器人不同，Agent 具有自主性、目标导向性和工具使用能力。

## Agent 的核心组成

### 1. 大脑（LLM）
- 负责理解、推理和规划
- 常用模型：GPT-4、Claude、DeepSeek、Llama
- 通过 Prompt Engineering 控制行为

### 2. 记忆（Memory）
- 短期记忆：当前对话上下文（Context Window）
- 长期记忆：向量数据库存储的历史信息
- 工作记忆：当前任务的中间状态

### 3. 工具（Tools）
- API 调用（搜索、数据库、文件操作）
- 代码执行（Python、Shell）
- 外部服务（邮件、日历、通知）

### 4. 规划（Planning）
- 任务分解：把复杂任务拆成小步骤
- 策略选择：决定用什么工具、按什么顺序执行
- 反思与修正：根据结果调整计划

## Agent 与传统 LLM 的区别

| 特性 | 传统 LLM | AI Agent |
|------|---------|----------|
| 交互方式 | 一问一答 | 自主循环执行 |
| 工具使用 | 无 | 可调用多种工具 |
| 记忆 | 仅当前对话 | 短期+长期记忆 |
| 规划 | 无 | 可分解复杂任务 |
| 错误处理 | 无法自我修正 | 可反思并重试 |

## Agent 的典型应用场景

1. **智能客服**：自动查询订单、退款、解答问题
2. **数据分析**：自动查询数据库、生成报表、发现异常
3. **代码开发**：自动写代码、测试、调试
4. **研究助手**：自动搜索文献、整理资料、生成报告
5. **流程自动化**：自动处理审批、通知、文档流转
